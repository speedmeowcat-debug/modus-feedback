# Modus Feedback — продуктовый ролик

60 секунд, 1920×1080, 60 fps (3600 кадров). Remotion + React + TypeScript, CSS 3D для 2.5D-камеры.

Ролик собран из настоящих компонентов приложения (`../src/components/ui.tsx`), его словаря статусов и типов (`../src/lib/domain.ts`), дизайн-токенов (`../src/app/globals.css`) и шрифта Golos Text. Данные взяты из демонстрационного датасета; новое обращение A-021 повторяет сценарий, проверенный в приложении.

Все моменты, движения и звуки задаются в одном файле: `src/film/timeline.ts`.

## Структура

```
src/
  index.ts, Root.tsx        композиции ModusFilm, ModusFilmSilent, ModusFinal
  style.css                 подключает токены приложения и Tailwind
  core/                     пружины, плавности, таймлайн (детерминированные, без Math.random)
  film/
    timeline.ts             тайминг сцен, музыка, 91 звуковое событие
    lib.tsx                 камера 2.5D, глубина резкости, курсор, цвета
    Film.tsx                сборка кадра, motion blur, звук
    ui/                     экраны приложения: список, форма, карточка, процесс, аналитика
    scenes/                 Opening (1–2), Product (3–5), Impact (6), Closing (7–8)
sound/                      звуковой движок: синтез музыки и эффектов из таймлайна
tools/                      render_audio.py, verify_sync.py
scripts/                    экспорт таймлайна, проверочные кадры
```

## Запуск

Нужны Node.js 20+, Python 3.10+ с `numpy` и `scipy` (только для пересборки звука).

```bash
npm install
```

```bash
npm run studio
```

Звук не хранится в репозитории: он собирается из таймлайна (`public/modus-film.wav`). Перед первым рендером и после изменений в `timeline.ts`:

```bash
npm run audio
```

Рендер:

```bash
npm run render
```

```bash
npm run render:final
```

```bash
npm run still
```

Результаты: `out/modus-feedback-film.mp4`, `out/modus-feedback-final.mp4`, `out/final-frame.png`.

### Windows: длинный путь к браузеру

Если проект лежит в глубокой папке, пути к встроенному Chrome Headless Shell и к ffmpeg превышают 260 символов, и рендер падает с `spawn … ENOENT`. Скопируйте по короткому пути две папки: `node_modules/.remotion/chrome-headless-shell/win64/chrome-headless-shell-win64` и `node_modules/@remotion/compositor-win32-x64-msvc`, затем укажите их:

```bash
set REMOTION_BROWSER=C:\chs\chrome-headless-shell.exe
```

```bash
set REMOTION_BINARIES=C:\rbin
```

Проще всего положить проект в короткую папку, например `C:\modus-feedback`: тогда переменные не нужны.

## Как сделаны эффекты

- **Камера.** Сцены живут в 3D-пространстве CSS; камера двигается по ключам с плавностями, каждый следующий ключ начинается из текущего положения, поэтому скачков нет.
- **Motion blur.** В окнах быстрого движения кадр собирается из 8 промежуточных положений (`@remotion/motion-blur`, затвор 180°). Размытие повторяет фактическую траекторию, а не накладывается фильтром.
- **Глубина резкости.** В первой сцене размытие карточки зависит от расстояния до плоскости фокуса, фокус переводится на новое сообщение и обратно.
- **Звук.** Музыка и эффекты синтезируются процедурно из того же таймлайна, сторонних записей нет. Каждый звук привязан к видимому событию, его кадр вычислен из движения. Проверка: `python tools/verify_sync.py out/timeline.json out`.

## Данные на экране

- Обращения A-001…A-020, роли и категории — из демонстрационного датасета без изменений.
- A-021 и его история повторяют сценарий из приложения; даты показаны для демонстрации.
- Показатели аналитики посчитаны по датасету с добавлением A-021: 21 обращение, завершено 24% (5 из 21), среднее время до первого ответа 13 ч по 16 обращениям. Даты демо-набора синтетические, на экране есть подпись об этом.
- Интеграции с Битрикс24 и 1С не реализованы и подписаны как планируемые.

## Версия на 90 секунд

Композиция `ModusFilm90` (`src/film90/`): новое кинетическое открытие, сцена ролей «Каждый видит своё», итоговая цепочка и все сцены 60-секундной версии. Звук на записанных SFX из библиотеки KantTools; сами сэмплы в репозиторий не входят из-за лицензии библиотеки. Чтобы собрать звук, положите их в `public/sfx/kant/` (имена файлов есть в `src/film90/timeline90.ts`) и выполните:

```bash
node scripts/export-timeline.mjs 90
SFX_SAMPLES=public/sfx/kant python tools/render_audio.py out90/timeline.json --out out90
```

Затем скопируйте `out90/audio.wav` в `public/modus-film-90.wav` и отрендерите:

```bash
npx remotion render src/index.ts ModusFilm90 out90/modus-feedback-film-90.mp4
```
