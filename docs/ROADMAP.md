# План развития

Сроки этапов не указаны намеренно: они зависят от состава команды и решений компании. Порядок отражает зависимость этапов друг от друга.

## Этап 0. MVP (сделано)

Сквозной процесс: подача, маршрутизация, рассмотрение, уточнения, итог, история, роли, фильтры, просрочки, аналитика, настройки. Подробно: `REQUIREMENTS.md`.

## Этап 1. Пилот в одном-двух подразделениях

Цель: проверить, что сотрудники подают обращения, а ответственные отвечают в срок.

| Задача | Зачем |
| --- | --- |
| Вход через Битрикс24 | Убирает отдельные пароли и ручное ведение пользователей |
| Синхронизация сотрудников и подразделений | Маршрутизация и обзор руководителя опираются на реальную структуру |
| Уведомления в Битрикс24 или на почту | Ответственный узнаёт об обращении, не заходя в систему |
| Напоминания о сроке и эскалация руководителю | Просрочка не остаётся незамеченной |
| Заместитель на время отсутствия | Сейчас обращения отсутствующего уходят одному резервному ответственному |
| Резервное копирование и мониторинг | Обязательное условие работы с реальными данными |

Проверка полезности (гипотезы, которые пилот должен подтвердить или опровергнуть):

- сотрудники подают обращения без напоминаний;
- доля обращений с первым ответом в пределах нормы растёт от недели к неделе;
- у большинства завершённых обращений зафиксирован итог;
- авторы возвращаются посмотреть результат.

Целевые значения определяются вместе с компанией до начала пилота (ТЗ 2.7).

## Этап 2. Развитие процесса

| Задача | Зачем |
| --- | --- |
| Конфиденциальные обращения | Канал для чувствительных тем: автора видит только доверенный сотрудник |
| Объединение дублей и связь обращений | Повторяющаяся проблема решается один раз, авторы всех дублей получают итог |
| Задача в Битрикс24 по принятому предложению | Реализация идёт в привычном инструменте, статус возвращается в обращение |
| Публикация реализованных улучшений | Сотрудники видят, что предложения приводят к изменениям (обращение A-020 датасета) |
| Оценка автором результата рассмотрения | Обратная связь на качество ответов |
| Выгрузка аналитики, период и сравнение периодов | Отчётность для руководства |
| Полнотекстовый поиск с морфологией | Поиск и подбор похожих на большом объёме |
| Шаблоны ответов и чек-листы по категориям | Быстрее и единообразнее ответы |

## Этап 3. Расширение аудитории

| Задача | Зачем |
| --- | --- |
| Опросы сотрудников | Регулярный сбор мнений по заданной теме |
| Клиентская обратная связь и NPS | Отдельный контур с внешним доступом по ссылке |
| Справочники из 1С для профильных категорий | Привязка обращения к номенклатуре или документу без ручного ввода |

## Требует отдельной технической проработки

- Способ интеграции с Битрикс24 (облако или коробочная версия, доступные права).
- Какие данные 1С допустимо показывать и кому.
- Размещение: инфраструктура компании или облако, требования к хранению персональных данных.
- Хранилище вложений и антивирусная проверка.
- Сроки хранения обращений и порядок удаления.
